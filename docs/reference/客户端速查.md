# 客户端速查

> 类型: reference
> 事实源: deploy/config.example.yaml,别名与端口以模板为准

## 事实表

| 项 | 值 |
| --- | --- |
| base-url | `http://192.168.88.10:8317`(主机名形 `http://lan-mac:8317` 需客户端具备该域解析,解析到同机另一网口,实测等效) |
| Claude Code 面 | `/v1/messages`,模型 `zp-cc-glm53`、`zp-cc-glm53fh`,裸名 `glm-5.3` 兜底(旧会话剥 `[1m]` 后仍发这个) |
| codex 面 | `/v1/responses`,模型 `zp-cx-glm53`、`zp-cx-glm5t` |
| chat 面 | `/v1/chat/completions`,模型 `zp-cx-chat` |
| 鉴权 | 网关 access key(Bearer 头),不是智谱 key;key 值见密码管理器 |
| `[1m]` 后缀 | 客户端侧 1M 上下文参数,CC 发请求前自剥;配置面写带后缀名,直打网关的 API 调用不写 |

## 不在本页

各客户端配置步骤与验活命令见客户端接入;网关换 key、冷却与边界行为见网关行为参考。
