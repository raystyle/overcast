# 客户端速查

> 类型: reference
> 事实源: deploy/config.example.yaml,别名与端口以模板为准

## 事实表

| 项 | 值 |
| --- | --- |
| base-url | `http://192.168.88.10:8317`(主机名形 `http://lan-mac:8317` 需客户端具备该域解析,解析到同机另一网口,实测等效) |
| Claude Code 面 | `/v1/messages`,智谱池 `zp-cc-glm53`、`zp-cc-glm53fh` + DeepSeek 池 `ds-cc-pro`、`ds-cc-flash`,裸名 `glm-5.3` 兜底(旧会话剥 `[1m]` 后仍发这个) |
| codex 面 | `/v1/responses`,智谱池 `zp-cx-glm53`、`zp-cx-glm53fh`、`zp-cx-glm5t` + DeepSeek 池 `ds-cx-pro`、`ds-cx-flash`(经网关翻译成 chat 发上游,上游 chat-only) |
| 响应头 X-Request-Id | 网关请求 id(UUIDv7),dialog2 起回写;与 stdout 末 8 位及 dialog JSONL 同 id,客户端凭此精确串联排障 |
| chat 面 | `/v1/chat/completions`,智谱池 `zp-cx-chat` + DeepSeek 池 `ds-cx-pro`、`ds-cx-flash` |
| 鉴权 | 现态关(任意串/无头均可,2026-10-13 裁定);开态=网关 access key Bearer 头;开关 `deploy/auth-toggle.sh on\|off\|status` |
| `[1m]` 后缀 | 客户端侧 1M 上下文参数,CC 发请求前自剥;配置面写带后缀名,直打网关的 API 调用不写 |

## 不在本页

各客户端配置步骤与验活命令见客户端接入;网关换 key、冷却与边界行为见网关行为参考。
