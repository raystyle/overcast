# 协同范式:herdr + s5 双栈

- 本仓自身的跨机协同范式,由立项单 ov-01(2026-10-11)固化;本单三件套即首个范例
- 协议权威源:evo-herdr:herdr-flywheel skill(派单、回执、断言、吸收四步循环);本文是本仓的执行摘要加 s5 过渡方案,条目与 skill 冲突时以 skill 为准

## 双栈分工

| 栈 | 管 | 面 |
| --- | --- | --- |
| herdr | **信号**:工位生命周期、派单 prompt、状态门控、事件驱动收执 | herdr workspace/agent/pane,跨机经 `--machine` 路由 |
| s5(Shared Store & Streams,仓 `s5_rs`) | **共享内容**:轮次档三件套、工件、轨迹流 | 文件走 S3 对象交换(put/get/ls/del),流走 S2 耐久追加 |

一句话:herdr 管信号,s5 管内容;盘上文件是确定稳态,herdr 生命周期态只是干预信号,验收一律以盘上三件套对账。

## 三件套契约,每笔交流一套

统一路径:`/tmp/herdr-flywheel/<轮次>/<单号>-{brief,state,receipt}.md`,原子写(先 `.tmp` 再改名)。

| 文件 | 谁写 | 管什么 |
| --- | --- | --- |
| `<单号>-brief.md` | 发起方 | 契约:任务清单逐件可判加验收判据;验收以笺为基准,判据派发时固化 |
| `<单号>-state.md` | 接收方 | 稳态:已接、在办、候裁、已交四检查点自写 |
| `<单号>-receipt.md` | 接收方 | 逐件对账:三态(过/缺/不适用)加自取证据(commit sha、退出码、行号引文);对方陈述不作数 |

本仓范例:轮次 `2026-10-11-overcast立项`,单 `ov-01`,三件套在 `/tmp/herdr-flywheel/2026-10-11-overcast立项/`。

## s5 键空间过渡

s5 CLI 候首版(仓 `s5_rs`,尚未定版),现阶段轮次档走**本机路径过渡**(即上表路径);首版可用后切 s5 键空间:

- 键形:`overcast/rounds/<轮次>/<单号>-{brief,state,receipt}.md`(路径即键,往返一致)
- 总台派单仍走 herdr prompt(prompt 自包含,brief 全文随 prompt 内联,跨机够不到本机路径);回执时 receipt 全文随回执内联,本机文件只作底稿与对账锚
- 断言面:总台按 receipt 文本对账,需要盘上核证时经 s5 get 取键空间档
- 切换裁定:等 s5 CLI 定版后立同步型周知单告知各工位,过渡期两通道并存以 s5 为准、本机路径为底稿

## 本仓工位纪律

- 收单先读 brief:无歧义写 state 已接;有歧义回问不硬开工
- 在办按检查点自更 state(心跳 = state mtime);候裁写清等什么等谁,不代用户裁
- 收工落 receipt 逐件对账,零改动也走已交(receipt 记零改动加一句理由)
- 会话回复只发 receipt 路径加一句摘要,全文在盘上
